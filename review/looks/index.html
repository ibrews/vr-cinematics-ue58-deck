Change the default look

In tools/bake_deck.py, change this one line:

DEFAULT_LOOK = "noir"  # Change this line, then rebake.

Replace noir with a look ID below, run python3 tools/bake_deck.py, then commit the bake config and generated index.html. Links with ?look=<id> preview without changing the default.
